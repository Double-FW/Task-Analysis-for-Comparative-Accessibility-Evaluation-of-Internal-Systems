# Related public Double-FW guidance

These repositories were confirmed public on 22 November 2026. They are optional specialist routes, not copied source bodies or hidden prerequisites. Public availability can change. If a route becomes unavailable, state the limitation, continue independent work using the local method and do not invent the linked contents.

| Resource | Relevant use |
| --- | --- |
| [Terminology and Principles](https://github.com/Double-FW/Terminology-and-Principles) | Shared meanings, status, authority and evidence conventions. |
| [QA accessibility testing](https://github.com/Double-FW/QA_Accessibility_Testing) | Choose technical outcomes and procedures and keep mappings separate from actual task evidence. |
| [Cognitive UX design](https://github.com/Double-FW/Cognitive-UX-Design) | Memory demands, comprehension, navigation, choices and task effort; retain owning CP identifiers. |
| [Data ethics and disability](https://github.com/Double-FW/Data_Ethics_and_Disability) | Plan appropriate participation and evidence handling; a pseudonym does not establish anonymity. |
| [Inclusive HR system governance](https://github.com/Double-FW/Inclusion-for-Managers-and-HR-Systems) | Workplace-system and governance context; do not turn comparative findings into employee ranking. |
| [Accessibility programme runbooks](https://github.com/Double-FW/Accessibility_Programme_Runbooks) | Plan actual owners, improvement work, dependencies and review arrangements. |
| [Inclusion and accessibility policy](https://github.com/Double-FW/Inclusion-and-Accessibility-Policy) | Distinguish proposed commitments, actual policy adoption and verified practice; establish legal applicability separately. |
| [AI accessibility maturity model](https://github.com/Double-FW/AI-Accessibility-Maturity-Model) | Connect appropriately evidenced system improvements to organisational capability without inferring maturity from a study. |
| [Accessible digital and printed documents](https://github.com/Double-FW/Accessible_Digital_and_Printed_Documents) | Prepare usable study materials and reports across appropriate reading formats. |

Record the exact revision and section actually used. A link does not establish a current external legal obligation, technical conformance, source inspection or permission to copy another work. Preserve source-owned meanings and rights; see [NOTICE](NOTICE.md). The [QA evidence map](QA_and_Comparative_Evaluation_Evidence_Map.md) explains how technical and task evidence support each other without becoming the same result.
