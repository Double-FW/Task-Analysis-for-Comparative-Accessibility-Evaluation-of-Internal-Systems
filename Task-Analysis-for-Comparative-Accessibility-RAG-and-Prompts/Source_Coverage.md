The folder adds four application/navigation files: its README, RAG reference, this inventory and the [activities and prompts](QA_Testing_and_Evaluation_Activities_and_Prompts.md). The activity file contains ten activities and twenty illustrative prompts and is substantive content included in the configured dataset export. The other three files support navigation and provenance; they are checked and listed in export provenance, not duplicated as dataset records.

The historical Sources directory duplicated the original four files and the embedded corpus duplicated them again. Maintained navigation now references the canonical files. Historical copies remain in Git history; do not combine them with current text as separate evidence. External source bodies, participant data, branches, issues and history are not part of this maintained corpus.

When changing content or the dataset export, review every intended source and folder file explicitly. Preserve complete text, relevant authority, evidence limits, attribution and rights. An inventory check is not evidence of a study, model evaluation, organisational adoption or product accessibility.
